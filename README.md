# MI 349 Portfolio

This repository contains my semester-long portfolio project for MI 349. The site started as a basic semantic HTML page, and I have been adding more styling and responsive features as the semester goes on.

## About the site

I'm an Information Science student at Michigan State University interested in web development, AI, human-centered technology, and Japanese language and culture.

I want this portfolio to be a place where I can show projects I have worked on while also experimenting with different web design ideas.

## Current design

For the current version, I went with a Y2K / early digital / glitch-inspired style. I wanted it to have a lot of personality without making it difficult to use as an actual portfolio.

Some of the design choices include:

- A black, off-white, gray, and blue color palette
- IBM Plex Mono and Michroma fonts
- Glitched text effects using `text-shadow`
- Blinking underscores on headings
- Scanlines across the background
- Y2K-style globe section dividers
- A barcode-style graphic in the footer
- Technical-looking project cards with harder borders and shadows
- A slightly different featured style for PokéRun
- Responsive layouts for different screen sizes

I tried to keep the main body text simple and readable, while using most of the glitch and Y2K effects on headings, dividers, cards, and other interface elements.

## Sections

- Home
- About Me

- Contact

The navigation uses anchor links to move between the different sections of the page.

## Projects

### PokéRun

A browser-based Pokémon project built around playing and tracking Pokémon games in one place. It includes an in-browser emulator, saves, run tracking, game information, and multiplayer work.

### D2L Assignment Dashboard

A Chrome extension that collects upcoming D2L assignments and due dates into one dashboard so I don't have to check every class separately.

### Task Memory API

An API project for storing memories, tasks, events, and reminders. I built it using Express, Prisma, and SQLite.

### Kanji Practice App / Japanese Companion App

A Japanese study tool for organizing readings, vocabulary, grammar, kanji practice, and flashcards in one place.

## CSS

The site has gotten a lot more CSS-heavy as I have worked on it. Some of the things I have been using include:

- CSS custom properties
- Flexbox
- CSS Grid
- Media queries
- Custom fonts
- Borders and shadows
- Pseudo-elements
- Hover states
- Transforms
- CSS animations
- Background gradients
- Responsive project layouts

The project layout starts as one column on smaller screens and changes on larger screens so some projects can sit next to each other while the featured projects take up more space.
