# MI 349 Portfolio

This repository contains my semester-long portfolio project for MI 349. The site started as a semantic HTML structure and I am now building out the visual design with CSS.

## About the site

I'm an Information Science student at Michigan State University interested in web development, AI, human-centered technology, and Japanese language and culture.

I want this portfolio to be a place where I can show projects I have worked on and keep improving the site as I learn more throughout the semester.

## Current design

For this version, I wanted the site to have a slightly Y2K / digital / glitch-inspired style without making it hard to read as a professional portfolio.

Some of the design choices include:

- A black, white, gray, and blue color palette
- IBM Plex Mono and Michroma fonts
- Glitched text effects using `text-shadow`
- Blinking underscores on headings
- Small symbols used throughout the interface
- Rounded project cards with drop shadows
- Faint horizontal background lines
- Styled project images and navigation

I tried to keep most of the body text simple so that the glitch effects are mostly used on headings and interface elements.
