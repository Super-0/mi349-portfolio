# MI 349 Portfolio

This repository contains my semester-long portfolio project for MI 349. The first version focuses on creating a clear structure with semantic HTML before I start adding CSS and visual design later in the semester.

## About the site

I'm an Information Science student at Michigan State University interested in web development, AI, and how people use technology. I want this portfolio to be a place where I can share projects I have made and keep adding to them over time.

## Sections

The portfolio includes:

- Navigation
- Intro
- About Me
- Projects
- Contact

The navigation links to each part of the page, so visitors can move around the site without leaving it.

## Projects

- **D2L Assignment Dashboard** — A Chrome extension that puts upcoming D2L due dates into one organized dashboard.
- **Kanji Practice App / Japanese Companion App** — A study tool for bringing Japanese readings, vocabulary, grammar, kanji practice, and flashcards into one place.
- **Task Memory API** — An API project for organizing memories, tasks, events, and reminders.

## What I'm practicing

- Semantic HTML
- Page navigation with anchor links
- Meaningful meta tags
- Images and external links
- ARIA labels where they are useful
- Organizing project information clearly

I checked the page with the W3C HTML Validator and fixed the errors it found.
