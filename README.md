# MI 349 Portfolio

This is my semester-long portfolio project for MI 349. Right now the site is focused on building the structure with semantic HTML, so there is no CSS yet.

The goal of this first version is to get all of the main content and sections in place before working on the design later.

## Sections

The portfolio will have:

- Navigation
- Intro
- About Me
- Projects
- Contact

The navigation will link to each section on the same page.

## About the Site

I'm an Information Science student at Michigan State University interested in web development, AI, technology, and Japanese.

I want the portfolio to be a place where I can show some of the projects I've worked on in class and outside of class.

## Projects I Might Include

- MI 349 Hello World page
- Japanese study/companion app idea
- AI and automation projects
- Other class or personal projects I work on during the semester

For each project I want to include a short description, what I used to make it, and what I learned from it.

## Things I'm Adding

- Semantic HTML elements
- Navigation links to each section
- At least one image
- An external link
- Meta tags in the `<head>`
- Lists and other HTML elements where they make sense
- ARIA labels where they are useful

## Validation

Before submitting, I'll run the page through the W3C HTML Validator and fix any errors that come up.
