Projects

Here are some projects I've worked on or plan to continue developing.

Kanji Practice App / Japanese Companion App

This project is a study tool for learning Japanese. It brings readings, vocabulary, grammar explanations, kanji practice, and flashcards into one place.

I want it to focus on making Japanese study material easier to work through instead of constantly switching between different resources.

Ideas for the project

  • Toggleable furigana
  • Vocabulary definitions
  • Grammar explanations
  • Flashcards

View the Kanji Practice App on GitHub

D2L Assignment Dashboard

I'm working on an assignment dashboard concept that makes it easier to see upcoming work across classes without checking each course separately.

It is a Chrome extension that collects upcoming due dates from D2L and puts them into one organized dashboard.

The goal is to make due dates and assignment details easier to scan, especially during busy weeks.

Task Memory API

Task Memory API is a local REST API for keeping track of memories, tasks, events, contextual lookups, and reminders.

I built it with Express, Prisma, and SQLite. One thing I learned from the project was how to make reminder delivery more reliable by avoiding duplicate reminders.

View Task Memory API on GitHub
